# Библиотека подготовки к senior frontend-интервью

Учебная **библиотека** для подготовки к собеседованию на позицию senior frontend-разработчика (стек Vue 3 / Nuxt).

**Читать на сайте:** https://alexrehtide.github.io/learning/

## Как устроена библиотека

- **Раздел** — крупная область знаний, одна папка (`javascript/`, `vue/`, …).
- **Тема** — один файл раздела по единому скелету: теория → примеры → вопросы с интервью → задачи → источники.
- **Ядро** — все разделы, кроме «Доступности» и «Тестирования»; они — **дополнительно**, облегчённой глубины.
- Основа — Vue 3.5, Nuxt 4 и Pinia 4; отличия других версий вынесены во **врезки**.
- Текст — на русском, код — на английском.

Термины — в [GLOSSARY.md](GLOSSARY.md). Как написать тему — в [docs/authoring.md](docs/authoring.md).

## Оглавление и порядок изучения

Порядок разделов: язык → платформа → вёрстка → фреймворк → инженерия (инструменты, производительность, безопасность) → архитектура → практика (live coding, алгоритмы) → дополнительно. Внутри раздела темы идут в порядке изучения.
